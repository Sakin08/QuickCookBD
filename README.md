# QuickCook BD - Meal Kit Delivery Platform

> Fresh Ingredients. Zero Prep. Ready in 20 Minutes.

## 🚀 About QuickCook BD

QuickCook BD is a meal kit delivery platform serving working professionals in Dhaka with authentic Bangladeshi meal kits. All ingredients are pre-cut, pre-marinated, and delivered fresh to your doorstep.

### Key Features

- ✅ **9 Authentic Bengali Meal Kits**
- ✅ **20-Minute Cooking Time**
- ✅ **One-Time & Subscription Plans**
- ✅ **Same-Day Delivery**
- ✅ **Real-Time Order Tracking**
- ✅ **Customer Reviews & Ratings**
- ✅ **Admin Dashboard with Analytics**

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The app will be available at `http://localhost:8443`

## 🌐 Deployment

### Deploy to Vercel (Recommended)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/YOUR_USERNAME/quickcook-bd)

**Quick Deploy:**

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel --prod
```
